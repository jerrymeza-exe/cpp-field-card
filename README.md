# C++ Field Card

A filterable C++ standard library cheat sheet for NeetCode and LeetCode problems: which container to reach for, the calls you actually use, pattern templates (BFS, DFS, topological sort, union-find, Dijkstra, and more), a Python-to-C++ table, and modern C++ and concurrency basics.

**View it:** https://jerrymeza-exe.github.io/cpp-field-card/

Press `/` on the page to filter. Every code card except the setup examples compiles with Clang as C++20.

Companion page: [Python Field Card](https://jerrymeza-exe.github.io/python-field-card/)
